Netwrix Config Exporter - Help

This extension exports configuration data from your Netwrix Endpoint Protector admin console to CSV, so you don't have to manually copy settings out of the UI.

1. First-time setup

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode (top-right toggle).
  3. Click Load unpacked and select the extension's folder.
  4. Confirm it appears as "Netwrix Config Exporter" with no errors.

2. Two ways to export

ButtonWhat it does
Export Current PageExports whatever page is currently open in the active tab - use this for pages not listed below, or for an individual item's detail/edit screen (e.g. one specific Content Aware Policy).
Section buttons (e.g. Global Rights, Mail Settings)Automatically navigates to that page for you first, then exports it. One click instead of clicking through the sidebar yourself.

3. Using it

  1. Open your Netwrix EPP admin console in a browser tab and make sure it's the active tab.
  2. Click the extension icon in the toolbar to open this popup.
  3. Click a section button, or navigate to a page yourself and click Export Current Page.
  4. A CSV file downloads automatically - check your browser's Downloads folder.
What's in the CSV: three columns - Category/Panel, Configuration Name, Value/Status. Each row is one setting, checkbox, dropdown, or table record found on the page.

4. Scope and limitations

  • List pages export summaries, not full detail. For example, "Content Aware Policies (List)" exports the policy names/status/priority table - not each policy's full rule configuration. To get one policy's full detail, open that policy's Edit page manually, then use Export Current Page.
  • The extension cannot auto-open individual rows. Opening a specific item (like one policy, one custom class) requires a real click from you - the app doesn't respond to script-simulated clicks on its row-action menus. Section buttons only work for pages reachable directly from the main sidebar.
  • Password fields are never exported, by design - for security.
  • Collapsed panels and inactive tabs are automatically expanded before export, so you'll get their data even if you never manually opened them (e.g. all tabs under Policy Denylists/Allowlists on a policy edit page).
  • If a page has genuinely no data (e.g. no alerts configured), the export will simply have fewer or zero rows for that section - that's correct, not a bug.

5. Troubleshooting

Nothing happens when I click a button: Make sure a Netwrix EPP tab is the currently active tab before clicking the extension icon. The extension always acts on your active browser tab.
Export stops working after the first click: This was a known bug (script re-injection colliding on Netwrix's single-page app navigation) that has been fixed. If you still see this, reload the extension in chrome://extensions.
A page you need isn't in the menu: Navigate to it manually in Netwrix EPP, then click Export Current Page in the popup - this works on any page, listed or not.

6. Adding more pages to the menu

The section buttons are defined in popup.html as data-path="Sidebar Item,Sub Item" - a comma-separated list of sidebar labels to click through in order. If you want a new page added, note its exact sidebar path and it can be added the same way.
